## 一、项目题目（固定/不重要）

**FoodLens：基于深度学习的食物图像描述与结构化膳食记录生成**



## 二、项目背景与任务描述

随着深度学习和视觉语言模型的发展，图像描述生成技术能够将视觉信息转化为自然语言，在智能图像理解、辅助信息获取等领域具有广泛应用价值。

食物图像具有类别丰富、食材组成复杂、外观差异细微等特点。相比一般场景图像描述，食物图像理解不仅需要识别食物类别，还需要关注食材、颜色、形状及烹饪特征等细粒度信息。

本项目以 FoodLens 为主题，围绕食物图像描述生成与结构化膳食记录生成两个核心任务，研究不同深度学习模型对食物视觉信息的理解与生成能力，并通过统一的实验设计比较不同模型的表现。

项目主要包含以下内容：

**任务一：食物图像描述生成（50 分）**

基于 Food\-500 Cap 数据集，自主实现至少两种符合课程规定的图像描述模型，使系统能够根据输入的食物图片生成相应的自然语言描述，并使用 BLEU、METEOR、ROUGE\-L、CIDEr\-D 等指标进行评价。

**任务二：结构化膳食记录生成（30 分）**

基于课程提供的膳食数据集，将输入的食物图像转换为符合预定义 Schema 的 JSON，包含食材名称及重量、整餐总重量、热量、蛋白质、脂肪和碳水化合物等信息。

至少比较任务一模型适配方案与经过参数高效微调的多模态预训练模型，并使用 F1、MSE 等指标评估预测效果。

**任选任务（20 分）**

计划完成以下两个方向：

- 强化学习优化：采用 SCST 等方法直接优化图像描述评价指标，并与交叉熵训练结果进行比较。

- LLM/VLM\-as\-Judge：使用多模态大模型从语义正确性、内容覆盖、幻觉和流畅度等维度评价生成描述，分析其与传统指标的一致性。



## 三、项目预期目标（被动确定）

本项目以满足课程要求、实现完整训练与评价流程、保证实验可复现为主要目标。

预期实现以下成果：

1. **图像描述模型：** 完成两种不同结构的图像描述模型，实现数据加载、模型训练、文本生成与模型评价。

2. **结构化生成：** 完成两条食物图像到结构化 JSON 的技术路线，支持食材识别、逐食材重量估计及整餐营养信息预测。

3. **模型比较：** 建立统一的评价体系，对比模型结构、训练方式和生成策略对实验结果的影响。

4. **任选任务：** 实现强化学习优化与多模态模型辅助评价，形成相应对照实验及分析。

5. **系统展示：** 开发基础交互原型，支持上传食物图像、生成文字描述、查看结构化膳食记录和展示模型结果。

6. **工程复现：** 提供完整代码、训练配置、模型权重管理、实验记录和运行说明。

项目不以提出全新网络结构为目标，而是通过自主模型实现、预训练模型适配以及科学的对比实验，体现对深度学习原理及实际应用过程的理解。

### 4\.1 图像描述生成

早期图像描述生成研究采用 CNN\-RNN 编解码结构，利用卷积神经网络提取视觉特征，并通过循环神经网络生成描述文本。

Show and Tell 等工作展示了视觉编码器与序列解码器结合的基本范式，为本项目的 CNN\+GRU 基线模型提供了参考。

随着注意力机制和 Transformer 的发展，图像描述模型逐步从全局视觉表示扩展到网格或区域特征，通过自注意力和交叉注意力机制进行跨模态信息融合。

Transformer 及后续图像描述研究为本项目采用网格视觉特征与 Transformer 编解码器提供了理论与结构设计依据。

### 4\.2 食物图像描述数据集

Food\-500 Cap 是面向细粒度食物图像描述的研究数据集，包含食物类别、食材及外观属性等描述信息。

项目拟以官方标注为依据，结合已经获取的社区图像资源构建训练数据，并针对图片重复、标注不一致等问题进行预处理。

### 4\.3 多模态预训练模型与参数高效微调

近年来，视觉语言预训练模型能够结合图像与文本信息完成视觉问答、描述生成和结构化内容输出等任务。

LoRA 等参数高效微调方法通过训练少量附加参数降低大模型适配成本，适合有限算力下的课程实验。

本项目计划参考 Qwen\-VL 系列模型及其官方微调方法，研究多模态预训练模型在膳食结构化生成任务上的适配能力。

### 4\.4 强化学习与大模型辅助评价

传统图像描述模型通常采用交叉熵进行监督训练，但训练目标与 BLEU、CIDEr\-D 等序列评价指标并不完全一致。

SCST（Self\-Critical Sequence Training）通过以模型自身推理结果作为奖励基线，实现对不可微评价指标的直接优化。

此外，基于 LLM/VLM 的评价方法能够补充传统词汇匹配指标在语义正确性、细节覆盖和幻觉判断等方面的不足，但其评价结果仍需通过对照实验验证可靠性。



## 五、技术方案

### 5\.1 系统总体架构

项目采用模块化设计，主要分为数据处理、图像描述模型、结构化生成模型、评价分析及系统展示五个部分。

整体流程为：

**食物图像输入 → 图像预处理 → 深度学习模型 → 描述文本或结构化 JSON → 评价分析与结果展示**

不同模型尽量共享数据接口、训练管理和评价基础设施，降低开发与集成成本。

### 5\.2 任务一：图像描述生成

计划自主实现两种模型。

**模型 A：ResNet \+ GRU**

采用 ImageNet 预训练 ResNet\-18 作为视觉编码器，提取图像整体特征，再通过特征投影与 GRU 解码器生成描述文本。

模型训练采用 Teacher Forcing 和交叉熵损失，自主实现视觉特征适配、序列解码、训练及推理流程。

**模型 B：ResNet Grid \+ Transformer Encoder\-Decoder**

使用 ResNet 提取图像空间网格特征，将其映射为视觉 Token，并输入 Transformer Encoder。Transformer Decoder 结合掩码自注意力和跨模态注意力生成描述文本。

计划采用轻量 Transformer 结构，重点实现位置编码、注意力机制、编码器和解码器的组合，以及自回归生成过程。

两种模型采用一致的数据划分和评价协议，通过比较不同视觉表示与文本解码结构的效果，分析其优缺点。

主要评价指标包括 BLEU、METEOR、ROUGE\-L 和 CIDEr\-D。

### 5\.3 任务二：结构化膳食记录生成

本任务计划采用两条路线。

**路线一：自主图像描述模型适配**

利用任务一训练得到的视觉编码器与解码器，在课程膳食数据上进一步训练，使模型能够输出规范化的结构化序列。

优先采用完整 JSON 序列生成方案，并使用 Schema 校验确保输出字段覆盖要求。

若数值预测表现不理想，进一步研究增加数值回归分支的方式，分别处理食材重量和整餐营养预测。

**路线二：多模态预训练模型微调**

初步选择 Qwen3\-VL\-4B\-Instruct，采用 LoRA 或 QLoRA 进行参数高效微调。

通过将食物图像与结构化膳食记录组成监督样本，使模型学习从图像直接生成指定格式的 JSON。

实验计划比较模型未经微调与微调后的表现，并与自主图像描述模型适配方案进行对照。

评价重点包括食材名称 F1、营养及重量数值 MSE、JSON 格式正确率和 Schema 有效率等。

### 5\.4 任选任务

**任选任务 A：强化学习优化**

在任务一交叉熵训练模型的基础上，引入 SCST，以 CIDEr\-D 等指标构造奖励函数，比较强化学习优化前后的描述质量和评价指标变化。

**任选任务 B：VLM\-as\-Judge**

构建基于图像与候选描述的多模态评价流程，从语义正确性、内容覆盖、幻觉和流畅度等方面进行评价。

通过模型间比较及部分人工评价，分析大模型评价结果与传统自动评价指标的一致性。

### 5\.5 数据处理与实验设计

任务一使用 Food\-500 Cap 官方标注及已下载的社区镜像图像数据。

目前已完成初步审计，发现标注数量差异、少量缺失样本及跨数据划分的重复图像。正式训练前将恢复可靠匹配的标注、排查重复，并固定训练、验证和测试数据划分。

任务二使用教学云提供的 3,258 条图像与膳食记录，其中训练集 2,338 条、验证集 414 条、测试集 506 条。

该数据包含完整 JSON 目标及逐食材重量信息。考虑到部分样本的食材重量之和与整餐总重量不同，系统将分别预测相关数值，不强制两者相等。

实验使用训练集进行参数学习，使用验证集进行模型选择和调参，保留测试集用于最终评价。对于审计中发现的潜在跨划分同餐样本，将记录并分析其可能造成的评测偏差。

## 七、组员分工及检查点

项目采用三人协作开发模式，设置组长一名，负责总体技术决策、项目统筹、接口协调、进度管理和最终交付。

**主要检查节点负责人：**

- 开题阶段：成员甲牵头，负责调研成果、数据依据及开题材料的组织。

- 中期阶段：成员乙牵头，负责原型验收、实验进度证据及中期成果整理。

- 结题阶段：组长牵头，负责最终实验验收、系统集成及结题材料。

各成员需保留相应代码、运行记录、实验结果和文档，作为工作完成情况的验收依据。

所有阶段性成果由组长统一审核，并通过教学云平台提交。

考虑到云 GPU 资源成本与模型训练的不确定性，项目将优先完成必选任务，再按阶段实施任选任务，并在各阶段预留调试和集成时间。



## 九、预期成果与风险控制

项目预计最终提交：

1. 两种自主实现的食物图像描述模型。

2. 自主模型与预训练多模态模型的结构化膳食记录生成方案。

3. 统一数据处理、训练、推理和评价代码。

4. 强化学习优化和 VLM\-as\-Judge 对照实验。

5. 实验结果、分析报告及可复现的运行说明。

6. FoodLens 基础演示系统。

7. 符合课程要求的结题报告及展示材料。

项目主要风险包括数据标注与镜像不完全一致、训练资源限制、模型微调不稳定、营养数值估计误差以及组员协作过程中的接口兼容问题。

拟通过数据审计、统一接口、预训练权重复用、参数高效微调、分阶段验收和实验记录等方式降低相关风险。

对于单幅 RGB 图像难以准确推断重量和营养成分的问题，将在实验中客观分析误差与方法局限，不将视觉估计结果等同于实际物理测量。
