## 一、课程设计概况

课程设计主题为 **FoodLens**，围绕食物图像的自然语言描述和结构化膳食记录生成开展实验。

课程设计满分 **100 分**，包含：

| 任务 | 性质 | 分值 |
| --- | --- | ---: |
| 任务一：食物图像描述生成 | 必选 | 50 分 |
| 任务二：食物图像到结构化膳食记录生成 | 必选 | 30 分 |
| 选做任务 | 三选二 | 20 分 |

### 分组要求

- 每组 **1—3 人**，设置 **1 名组长**。
- 各组员须明确分工，每个人的工作检查点须清晰、可度量，并会影响评分。
- 项目过程中的不同检查节点，须由**不同组员主要负责**。
- 所有提交物由组长通过**教学云平台**统一提交。

## 二、必选任务一：食物图像描述生成（50 分）

### 任务目标

输入一张**食物图像**，由模型输出与图像内容相符的**自然语言描述（Caption）**。

### 数据集

**Food-500 Cap**。

教师补充材料给出的标注样例为：

```json
{
  "cat": "Abalone",
  "filename": "Abalone/Abalone_0083.jpg",
  "caption": "Two pieces of boiled abalone slices on sushi rice placed on the top of sue cotyledons in a shell of an abalone."
}
```

其中 `cat` 是食物类别，`filename` 是图像路径，`caption` 是图像对应的自然语言描述。任务要求模型根据图像**生成描述文本**，不是仅输出食物类别或复制输入标注。

### 模型要求

至少**新实现**下列五种模型结构中的**两种**：

1. CNN / ViT 整体表示 + GRU。
2. 网格 / 区域表示、自注意力 + 注意力。
3. 网格 / 区域表示、Transformer 编码器 + Transformer 解码器。
4. 网格 / 区域表示、图网络 + Transformer 解码器。
5. 视觉 Transformer + Transformer 解码器。

### 评测要求

至少使用以下五种标准中的**三种**：

- BLEU
- METEOR
- ROUGE-L
- CIDEr-D
- SPICE

## 三、必选任务二：食物图像到结构化膳食记录生成（30 分）

### 任务目标

输入一张**食物图片**，输出满足预定义 **Schema** 的 **JSON 膳食记录**。

输出内容至少涵盖：

- `items`：食物原料列表，其中包含原料名称；示例中每项包含 `name` 和 `weight_g`（重量，克）。
- `total_weight_g`：整餐总重量，单位为克。
- `total_calories_kcal`：整餐总热量，单位为千卡。
- `protein_g`：蛋白质，单位为克。
- `fat_g`：脂肪，单位为克。
- `carbohydrate_g`：碳水化合物，单位为克。

教师补充材料给出的**示例目标输出**：

```json
{
  "items": [
    {"name": "yam", "weight_g": 94.0},
    {"name": "watermelon", "weight_g": 87.0}
  ],
  "total_weight_g": 181.0,
  "total_calories_kcal": 142.8,
  "protein_g": 2.0,
  "fat_g": 0.4,
  "carbohydrate_g": 34.2
}
```

上述数值仅为课程示例，不是固定预测结果。

### 数据集

**教学云平台提供的数据集**。原始任务 PPT 未给出该数据集的下载地址、联系人、样本数或具体文件组织方式。

### 模型比较要求

至少比较**两种模型**：

1. **任务一中实现的图像描述模型**。
2. **经过全量微调或参数高效微调的多模态预训练模型**。

### 评测要求

- 任务一的评测指标。
- **F1**。
- **MSE**（均方误差）。

## 四、选做任务（三选二，合计 20 分）

### 方向一：强化学习优化描述指标

使用强化学习直接优化 **CIDEr-D、实体 F1 或综合奖励**，比较强化学习训练与**交叉熵训练**的差异。

### 方向二：引入 LLM-as-Judge

使用大模型评价图像描述的：

- 语义正确性；
- 内容覆盖；
- 幻觉；
- 流畅度。

分析大模型评价与**传统指标或人工评价**的一致性。

### 方向三：单图像营养估计极限挑战

输入一张普通的**食物 RGB 图像**，预测整道菜的：

- 总质量；
- 总热量；
- 蛋白质；
- 脂肪；
- 碳水化合物。

可使用**任务二的数据集**，也可加入 **OmniFood8K** 等其他数据集进行评测，参考任务二的指标。

本方向**方法完全开放**：允许模型训练、深度估计、多视角生成、几何推断、RAG、知识图谱、大模型、外部 API、Agent 工作流、模型集成等方法。

但必须遵守以下严格限制：

- **严禁**任何形式的测试集泄漏、答案检索、人工修正、样本级硬编码或使用测试集调参。
- **测试前必须冻结完整系统**。
- **测试阶段仅允许输入规定的 RGB 图像，并自动生成结果**。

### 2. 中期阶段（第 14—15 周）
